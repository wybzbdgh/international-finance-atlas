# 国际金融课程网站

[访问课程网站](https://wybzbdgh.github.io/international-finance-atlas/) · [修改指南](docs/editing.md)

技术结构为 HTML、CSS 和 JavaScript，无 TypeScript、JSX 或 React。正文放在独立的 HTML 文件中；原有外观、地图与课程交互保留。

国际金融课程小组网站，包含每日参考汇率地图、课程读本和理论深思。读本按课程大纲的六个模块组织，覆盖讲义的 20 个专题，配有历史案例、随文图表及 40 道练习。理论深思按原著年代组织 46 篇文章，解释原著背景、假设、推导与争论。

主导航为 **全球汇率 / 课程读本 / 理论深思**。

正文按节与小节连续阅读。重复的侧栏计算器已并入随文图表，保留的三角套利、融资成本、三元悖论和稳定币计算嵌入对应小节。各专题有学习要求、公式或比较表、两道附解析的练习；相关专题提供历史案例、论文入口和参数交互。案例包括广场协议、人民币“8·11”汇改、亚洲金融危机、中国香港金融保卫战、2008 年全球金融危机、欧债危机、阿根廷 IMF 贷款与对俄金融制裁。

交互包括国际账户记账与估值、三角套利、相对购买力平价、利率平价、超调路径、政策传导、风险分担、三元悖论、货币错配、债务动态、本外币融资成本、远期及期权套期、支付限制与稳定币赎回。地图中的国家还提供相关专题入口。

另有八处随文交互：货币制度时间轴与对照、国际收支卡片分类（拖动或点选）、政策传导排序、回购融资挤兑的分步操作、金融安全网工具比较、人民币使用范围与功能判断、货币负债与支付轨道的两层图解、国际货币体系条件组合。它们直接放在相关正文之后，并可从本篇目录跳转。

本次增加金本位调节、两期消费、国际投资头寸估值、巴拉萨—萨缪尔森机制、CIP 现金流、J 曲线、货币错配、回购融资、资本流动与政策、货币冲击联动图等十组图表。

原有随文图表包括经济份额与货币使用、国民账户衔接、外汇成交份额、巨无霸价格、相对 PPP、UIP、汇率超调、IS-LM-FX、风险分担、证券化损失分层、债务路径、股市市值、套保曲线、美元网络、支付路径、CIPS 与储备分散化。可点选、切换指标、调整参数，曲线支持触摸及键盘读数。数据转录与模型条件见 [图表说明](docs/interactive-figures.md)。

页眉使用用户提供的光华管理学院原图，通过 SVG 滤镜将原有红黑笔画显示为白色、背景透明，原始文件未重绘。为保持白色标识的辨识度，日间阅读也使用深色页眉。

## 课程与资料

正文依据用户提供的陈泽丰《国际金融学：大国崛起视角》（讲义版／教材初稿，2026）和《国际金融课程大纲：2026 秋》。以原文节选为主，整理段落、公式及参考文献标注，并删除依赖书内图表和章节位置的说明。课程来源保留在本说明中，网页不显示讲义页码及出处索引。公式说明、交互、练习与解析另行编写。完整讲义 PDF 未上传到公开仓库。

文献导读提供 Cassel（1918）、Mundell（1963）、Dornbusch（1976）、Krugman（1979）、Diamond 与 Dybvig（1983）、Kose 等（2006）及 Rey（2015）的原始论文入口，并说明模型条件或经验边界。

## 理论深思

时间目录涵盖古代货币思想、重商主义与古典调整机制、两次大战之间的汇率关系、战后开放经济模型、浮动汇率理论、资本开放与危机、全球金融周期与数字货币。可以按作者、理论名称、年代搜索，也可按理论、经验难题、制度方案和思想前史筛选。

各篇附原著入口。可核对的原文使用短摘，译文单独标注；解读结合用户提供的课程讲义编写，不能视为原作者逐字表述。现代论文没有全文转载。课程正文首次出现的相关术语链接至文章；返回课程时恢复阅读位置。相关课程入口可定位到正文小节。

- 内容：public/pages/theory/，每篇文章一个 HTML 文件。
- 来源核查：docs/theory-sources-early.md、docs/theory-sources-modern.md。
- 搜索与导航索引由 scripts/build-content.mjs 从 HTML 生成，文章按需加载。
- 字体：思源宋体用于阅读；思源黑体与 Inter 用于界面和数字；KaTeX 排版公式。四份中文字体子集覆盖实际正文，生成方式见 src/assets/fonts/README.md。

## 数据与模型口径

- **汇率**：来自 [Frankfurter](https://frankfurter.dev/)，为每日参考价，非盘中实时价或银行可成交报价。非交易日可能沿用最近数据日。报价、历史数据或地图无法取得时显示说明及重试入口。
- **地图**：242 个国家及地区边界，支持点击、搜索和键盘选择，提供地球／平面视图。先选国家，再选人民币、美元、日元、欧元、英镑或瑞士法郎。报价为每单位本币可兑换的目标货币数量，附反向报价和金额换算。30 日变化相对所选币种计算；±0.5% 内作为小幅变化，无报价或币制更替时不比较涨跌。
- **历史走势比较**：地图显示最新参考价。国家走势图与多币种比较分别选择一个月、三个月、一年或五年；比较图另有“自定义时间”，可在近十年内拖动或输入起止日期，应用后更新曲线。支持指针、触摸和键盘读数。最多比较四种不同货币，以共同日期为 100，不补齐缺失观测或拼接不同货币单位。
- **货币区域与汇率制度**：高亮当前使用同一主要货币的地区，可展开名单并选取国家。汇率制度使用 IMF 2025 年报的实际安排分类，固定于资料日期，地图显示四组，国家面板显示具体类别及日期。货币更替与制度来源见 [地图数据说明](docs/map-data.md)。
- **边界与币种**：[Natural Earth 1:50m](https://www.naturalearthdata.com/) 边界为公有领域数据。币种匹配派生自 [world-countries](https://github.com/mledoze/countries)，多币种地区只选一个主要币种演示。派生数据库 public/data/countries.json 按 ODbL 1.0 共享，条款见 public/data/ODbL-LICENSE.txt。
- **国际账户**：沿用讲义 BPM6 符号，金融账户为资产净获得减负债净产生，净贷出为正。经济所有权转移时记录出口；收款不重复记录出口。居民之间转让外部资产不新增国际收支交易。净头寸变化另外区分价格和汇率估值。
- **套利与平价**：三角套利逐笔使用买价或卖价；价差按中间价两侧对称设定。CIP 使用同期限、简单计息基准。远期价格不是未来即期汇率的确定预测。实际汇率 q 上升表示实际贬值；有效汇率指数按通常方向设定，基期 100、上升表示升值。
- **政策与超调**：小型开放经济、短期价格粘性、给定预期和风险。IS–LM 示意只表示调整方向。随文超调中 m、p 为相对冲击前稳态的对数偏离，采用货币市场 m−p=−λ(i−i*)、价格调整 dp/dt=θ(m−p)、UIP de/dt=i−i* 及长期 PPP 的一致闭式路径；价格方程为教学用约化设定，未估计完整结构模型。资本流动比较另用明确标注的 IS–LM–BP 模型。
- **债务**：债务率使用名义利率与名义 GDP 增长率，初级盈余为正。到期比例另外决定总融资需求；重组现金流按同一折现率比较现值。债务偿清后不显示进一步盈余形成的资产。
- **企业融资与套期**：比较同币种、同期限的偿付现金流，费用按本金比例计。期权费按套期美元金额计、不计其时间价值。自然对冲单独展示收款与偿债相抵后的净额；不将它与借款前的总收款混比。
- **支付**：四个环节为合同义务、报文、清算与结算，托管为平行的资产控制层。限制的作用对象需要分别判断，更换币种不自动改变机构与资产受到的限制。
- **稳定币**：先用现金，再按折价变现证券，按顺序兑付至储备耗尽。展示现金缺口、未满足赎回与剩余保障率，未模拟价格反馈或破产分配。
- **回购融资**：沿用讲义的 100 亿元抵押品、95 亿元借款和折扣率提高后的 20 亿元融资缺口。分步比较出售抵押品、取得过桥资金与偿还回购；净资产按证券加现金减两类负债计算。后续折价出售和过桥额度为教学设定。
- **体系情景**：按第三方使用、市场深度、公共流动性与网络衔接进行条件归类，不输出概率或预测日期。
- **配图**：public/assets/export-port.webp 为 AI 生成的港口教学情境图，不作为历史事件证据。

## 设计与阅读

冷灰与薄荷色，支持夜间与日间阅读。标题与正文使用思源宋体网页子集；导航及控件使用 Inter，中文界面使用思源黑体网页子集。数字使用 Inter 的等宽数字设置，零不带斜线。字体自托管，使用 font-display: swap。

桌面采用本篇目录与正文两栏，模型和交互放在相关段落之后。手机提供专题下拉菜单，交互面板自然展开，表格可横向滚动。核心正文默认显示。地图与动画尊重系统的减少动态效果设置。旧版主要锚点保留对应入口。

字体来源、许可证及子集更新方法见 [字体说明](src/assets/fonts/README.md)。新增正文后运行 scripts/subset-fonts.py，脚本会收集课程、理论文章及界面中的全部字符，并检查中文字形覆盖。

## 在 Mac 上运行

需要 Node.js 24 与 pnpm 11。

    git clone https://github.com/wybzbdgh/international-finance-atlas.git
    cd international-finance-atlas
    pnpm install
    pnpm dev

打开终端显示的 HTTP 地址。不要在 Finder 直接双击源码 index.html；文件方式打开会显示公开网站入口。

    pnpm build
    pnpm preview

## 发布

.github/workflows/deploy.yml 在 main 更新后构建并部署到 GitHub Pages。仓库 Settings → Pages 使用 GitHub Actions。Vite 根据 GITHUB_REPOSITORY 设置仓库子路径，站内使用 hash 路由。

## 维护

- public/pages/course/：课程目录、20 篇正文、案例、文献、公式、表格与练习。
- public/pages/theory/：年代目录与 46 篇理论文章。
- src/course-data.json、theory-data.json、theory-index.json：自动生成的数据，不直接编辑。
- src/content.js：课程导航与专题别名。
- src/lib/models.js：套利、融资、债务、套期与储备计算。
- src/lib/fx.js：货币对套算、相对涨跌与历史序列整理。
- src/lib/activities.js：回购融资账目与货币体系情景条件。
- src/activities-data.js：随文交互中的例子、制度对照与讲义摘录。
- src/components/ReadingActivity.js：八种随文交互。
- src/components/Experiments.js：交互入口、记账、政策、危机与支付。
- src/components/AdvancedExperiments.js：其他计算工具。
- src/components/ExperimentUI.js：控件、数值格式与图表。
- src/components/WorldAtlas.js：地图图层、国家选择、币种和金额换算。
- src/components/AtlasMap.js、AtlasCharts.js：WebGL 地图与交互历史曲线。
- src/map-data.js、currency-names.js：带日期的币种映射、IMF 制度分类及中文币种名称。
- src/lib/atlas-models.js、atlas-rates.js：共享日期的指数比较、汇率查询缓存和状态。
- src/main.js：文章加载、导航与主题切换；src/course-directory.js：全文搜索及练习。
- src/styles.css：字体、主题和阅读布局。

更新正文时对照讲义口径；更新计算时核对币种、单位、期限、现金流与符号。发布前构建并检查数值、路由、地图选择和手机布局。
