# 理论深思：现代文献与内容核对

核对日期：2026-10-03。范围：`public/pages/theory/` 的 24 篇文章。

## 编辑口径

- 年代采用本条所选论文已核对的首发版本，工作论文、演讲与期刊年份在页面上分别注明；不把一个成熟研究领域归结为此篇论文唯一首创。
- 正文是结合用户提供的《国际金融学》讲义撰写的中文解读，不标为原著逐字翻译。英文短摘逐条与作者、期刊、大学保存的原刊或 NBER 页面核对；译文为本站自译。
- 现代论文仅展示短摘和来源入口，不复制全文。单个来源的英文短摘不超过 25 词；同一原作的不同镜像视为同一来源。
- 主权违约条目能够核对期刊元数据，但未取得足够可靠的原文文本，保留原刊入口，不编造引文。ResearchGate 的相应条目摘要出现与论文不符的学习模型内容，未采用。
- 公式是课程口径或注明的简化表达；数值算例为教学设定。均已用 KaTeX 检查语法。

## 讲义核对范围

使用工作区已有的 `work/notes.txt`，重点核对国际账户与跨期分析、金融全球化、利率平价、三难与浮动隔离边界、货币危机、外币债务、美元融资和货币体系等部分。讲义中的 60/100 两期消费例子与卢卡斯的 15 倍产出、58 倍边际产出计算，在正文交代为讲义沿用的例子；追加的正利率、借款约束、债券违约定价、银行清算及贸易合同算例均标明教学性质。页面不列讲义页码。

## 关联图形的边界

- 跨期经常账户关联 `intertemporal-choice`，与预算约束、消费平滑和借款约束相配。
- 主权违约关联债务动态，正文另设“配图观察：偿付能力”，说明会计路径不包含内生违约选择。
- 戴蒙德—迪布维格关联回购流动性图，正文明确这是影子银行延伸，原模型讨论储户类型与提款协调。
- 法马之谜关联 UIP 基准图，明确图形只说明被检验的理论，经验难题需要实际样本。
- Redux 与全球金融周期不挂普通 IS–LM–BP 图，避免把基准静态图误认成原研究模型。
- 其他图形作为文中所解释机制的简化观察工具；读者仍应从正文核对模型范围。
