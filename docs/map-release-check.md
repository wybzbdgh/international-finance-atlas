# 地图调整与发布检查

## 设计判断

使用 `design-taste-frontend` 的保留式调整流程。原站已有光华白色标识、深色页眉、思源宋体、思源黑体、Inter、薄荷色和细边界线。全球汇率、课程读本、理论深思及既有路由继续沿用。

调整前，标题单独占左栏，地球居中但面积偏小，右侧只有报价和单条曲线。新的布局将标题移到上方，地图占宽栏，右侧按国家、报价、目标币种、金额、走势排列；时间轴与比较图单独展开。已删除的出口风险跳转没有恢复。

设计参数为 `DESIGN_VARIANCE: 6`、`MOTION_INTENSITY: 3`、`VISUAL_DENSITY: 4`。不使用展示性滚动动画；转动、缩放和播放用于浏览地图或切换数据。相机过渡遵循减少动态效果设置。

新增控件采用 4px 圆角，播放按钮用圆形表达动作。分类配色仅用于数据：涨跌用薄荷与浅红，制度四组用低饱和分类色，比较线沿用读本的图表色。其他区域使用原有中性色。地图分类层的选中与悬停不再覆盖填色；主要采用边界标记。平面视图完整居中，避免重复世界副本。

中文标题保留用户指定的思源宋体；界面中文采用思源黑体，数字和西文采用 Inter。字体、既有 Lucide 图标与导航保持原站体系。真实的地理数据和汇率曲线是页面主体，没有添加装饰图片、营销数字、眉题或卡片墙。
